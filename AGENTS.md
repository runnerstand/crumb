Crumb is a native Android app using Kotlin and XML layouts.

UI rules:
- Use Android XML layouts
- Use ViewBinding
- Use Material Components
- Use Fragments and BottomNavigationView
- Use RecyclerView for lists
- Do not reintroduce Jetpack Compose
- Do not modify Retrofit, DTOs, repositories, ViewModels, backend routes, or database logic unless explicitly requested
- Keep all existing CRUD behavior working
- Build after every UI change
